# Final-Project-Movie-Reviews

## Overview
Deep learning tools to classify movie reviews as Lingering, Enjoyable or Forgettable.

## Data
- Letterboxd Reviews dataset
- Manually labeled subsets of reviews
- Movie metadata dataset

## Methods
- Manually label reviews
- LSTM
- BERT transformer
- Merge predictions with metadata
- Analyze and find insights

## Results
BERT classified unlabeled Letterboxd reviews as lingering, enjoyable or forgettable. With movie metadata dataset, insights could be gathered. Models did not have great accuracy, and therefore insights were not great. More training data is preferable in future work.
